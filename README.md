# FALLEN — Tower of Fortune

Неоновый гиперказуальный рогалик-аркада для браузера. Сфера падает сквозь бесконечную процедурную башню: собирайте монеты, обходите лазеры, пилы, шипы и каменные глыбы, проходите гейты «БЕЗОПАСНО / РИСК», побеждайте боссов каждые 100 этажей и прокачивайте сферу между забегами.

Одна страница, ноль внешних зависимостей (кроме официального Yandex Games SDK), звук генерируется WebAudio, вся графика рисуется на canvas.

## Запуск

Вариант 1 — просто открыть файл:

```
index.html
```

Двойной клик по `index.html` (или перетащите в браузер) — игра запускается локально без сервера.

Вариант 2 — локальный статический сервер:

```
python3 -m http.server 8080
# http://localhost:8080
```

Всё, что нужно игре, лежит рядом с `index.html`: `game.js`, `style.css`, `assets/icons/*.svg`.

## Управление

| Действие | Клавиатура | Сенсор |
|---|---|---|
| Влево | `←` или `A` / `Ф` | Палец слева от центра / перетаскивание |
| Вправо | `→` или `D` / `В` | Палец справа от центра / перетаскивание |
| Пауза | Кнопка в HUD | Кнопка в HUD |

Сфера падает сама — игрок управляет только горизонтальным положением. Вращение устройства не требуется: канвас заполняет экран в любой ориентации, полосы не появляются.

## Игровые системы

**Башня.** 8 зон по 50 этажей, цикл бесконечный; у каждой зоны свой цветовой фон, набор опасностей и музыкальная тема. Каждые 25 этажей — гейт выбора: «БЕЗОПАСНО» (меньше монет, пилы ниже) или «РИСК» (в 10 раз больше монет, пилы агрессивнее).

**Боссы.** Каждый 100-й этаж — босс-зона (640 px). Пять типов:

1. **Лазер** (100) — вращающееся трезубце-ядро;
2. **Дробилка** (200) — три ряда сдвижных плит с бегущим зазором;
3. **Бездна** (300) — пять дрейфующих орбов-воронки;
4. **Магнит** (400) — три орба, притягивающих сферу;
5. **Глыбы** (500) — снаряды, падающие по дугам с прицеливанием по игроку.

Победа = прохождение зоны: +1500 монет, счётчик побед в статистике.

**Перки.** На случайных этажах — портал перка: выбор из 3 вариантов (магнит, двойные монеты, щит, замедление, удача, призрак, пламя, перо, золото, овердрайв) с редкостями.

**Сундуки.** Четыре редкости (обычный, редкий, эпический, легендарный) — монеты, перки, иногда скины.

**Прокачка.** 6 улучшений: магнит, ускорение, щит, удача, монеты, ревайв. Цена `base × 1.18^level`, максимум 20-й уровень. Ревайв: бесплатное воскрешение при 5+ уровне, плюс платное «ИГРАЛЬНАЯ ВЕЧЕРИНКА» после смерти (x15 или x0, одноразово за забег).

**Ежедневки.** 7-дневный календарь наград (100/150/200/300/400/600/1000) + 3 ежедневные квесты (этажи, монеты, боссы) + 24 ачивки.

**Скины.** 15 скинов сферы (цвет, трейл, аура), открываются монетами и сундуками.

## Yandex Games SDK

Интеграция вынесена в адаптер (внутри `game.js`, блок `SDK`):

- **Локально** (без Yandex) адаптер — безопасный no-op: `ready = true` сразу, все вызовы игнорируются, игра не ломается и не показывает ошибок.
- **На Yandex** используются только официальные методы:
  - `Adv.showRewardedVideo` — только по осознанному действию игрока (кнопка на экране смерти); кнопка скрыта, если реклама недоступна; после успешного просмотра — возврат в уровень и 2.5 s неуязвимости;
  - `Adv.showFullscreenAdv` — только в логических паузах (после забегa, перед новым), собственный кулдаун 100 s, `GameplayAPI.stop()` до показа и `start()` после, звук глушится на время рекламы;
  - `Leaderboards.submit` — лучший этаж, только при обновлении рекорда;
  - `YG.getUser` — только по добровольному действию, с объяснением в UI; регистрация/почта/пароль не требуются никогда.
- `GameplayAPI` корректно останавливает/возобновляет игровой процесс вокруг рекламы.

## Аудио и качество

- Музыка: процедурные WebAudio-паттерны, отдельная тема на зону, особые темы босса; SFX: монеты, удары, смерть, перки, UI.
- Пауза + полная остановка звука при потере фокуса окна/вкладки (`blur`, `visibilitychange`); корректное возобновление.
- Три уровня качества (HIGH / MED / LOW): количество частиц, трейлы, тени — настраивается в панели.
- Ошибки не показываются игроку: никаких `alert`/stack trace в UI, диагностика — только в консоли.

## Языки

RU (по умолчанию) и EN — полная локализация UI (`I18N` в `game.js`), переключается в панели; активное обновление строк при смене.

## Структура проекта

```
index.html          точка входа (canvas + UI-обвязка)
style.css           стили, glassmorphism-панели, адаптив, safe-area
game.js             собранная игра (единый файл, см. «Сборка»)

assets/icons/       22 SVG-иконки UI (без эмодзи и битмапов)
bot.js              ИИ-игрок для headless-проверок (только клавиши + debug-высокий контроль при боссах)
check_harness.js    Node-обвязка: фейковый DOM/canvas/аудио, запуск game.js без браузера
smoke_check.js      16 сквозных проверок: старт, сохранения, магазин, скины, ежедневки, квесты, лидерборд, настройки, забег, выживание, смерть, гембл, пауза/фокус, сброс
README.md           этот файл
```

## Сборка

`game.js` — конкатенация частей в фиксированном порядке:

```
cat parts/p0[1-9].js parts/p1[0-3].js > game.js
node --check game.js
```

Части: `p01` каркас/конфиг/утилиты, `p02` сохранения, `p03` i18n, `p04` прогресс/квесты/ачивки, `p05` SDK-адаптер, `p06` аудио, `p07` процедурный мир, `p08` физика/ввод, `p09` контроллер забега и боссов, `p10` частицы/тексты, `p11` UI-экраны, `p12` панели (магазин/скины/квесты/настройки), `p13` рендер/цикл/отладочные ручки.

## Автоматические проверки

Node.js (>= 18), браузер не нужен:

```
node smoke_check.js
```

16 проверок покрывают загрузку, SDK no-op, i18n, цикл сохранений, магазин, скины, ежедневные награды, квесты/ачивки, лидерборд, настройки, старт забега, 40-секундное выживание ИИ-игрока (этаж 12+, 100+ монет, 0 ошибок), смерть и статистику, гембл, паузу/потерю фокуса, возврат в меню и сброс. `smoke_check.js` завершается с кодом 0 только если все 16 проверок зелёные.

`bot.js` — приличный, но честный ИИ: каждый кадр перебирает горизонтальные полосы-кандидаты и штрафует за каждое препятствие в окне обзора (лазеры, пилы, шипы, плиты гейтов, хазарды боссов). При боссах-«таймингах» (дробилка, лазер) используется отладочное управление вертикалью через `FALLEN_DEBUG.setVy` — горизонтальное позиционирование остаётся настоящим.

## Технические ограничения (соблюдены)

- Один HTML-файл на входе, все имена файлов ASCII, без пробелов;
- ZIP-архив проекта < 30 МБ (фактически < 1 МБ), распакованный проект << 100 МБ;
- Нет тяжёлых библиотек: вся графика canvas 2D, звук WebAudio, иконки SVG;
- UI без скролла страницы, без зума на таче, без контекстного меню и выделения текста в процессе игры; тач-цели ≥ 44 px, учтены safe-area.
